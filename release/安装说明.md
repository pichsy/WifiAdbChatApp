# 文件互传助手 2.2.0 · Windows 安装包

本目录存放编译好的 Windows 可执行程序。

## 内容

| 文件 | 说明 |
| --- | --- |
| `文件互传助手-2.2.0-安装包.exe` | 带安装向导的安装程序（约 28 MB）。内部已包含 .NET 8 运行时，**目标机器无需安装 .NET** |

## 安装

1. 双击 `文件互传助手-2.2.0-安装包.exe`；
2. 欢迎页点「下一步」，在「选择安装位置」页选择目录（默认 `D:\Program Files\文件互传助手`，
   也可以点「浏览」或直接改成别的路径），点「安装」；
3. 安装完成后进入「安装完成」页，页面下方有：
   - ☑ **创建桌面快捷方式**（默认勾选，点「完成」时才创建）
   - ☑ 立即运行 文件互传助手（默认勾选）

   按需取消勾选，然后点「完成」。
4. 桌面/开始菜单出现「文件互传助手」即可启动。

> 2.2.0 起点窗口右上角 ✕ 只是收进托盘（后台继续收发），并不会退出程序。
> 安装 / 卸载前如果程序正在后台运行，先右键托盘图标 →「退出文件互传助手」。

安装程序只会往你选的目录里放东西：主程序 `ADBTypeLink.App.exe`、三个原生库
（`libSkiaSharp.dll`、`av_libglesv2.dll`、`libHarfBuzzSharp.dll`）、`app.ico`、`uninst.exe`。
程序运行时也从该目录直接启动，**不会再把程序文件解压到 `C:\...\Temp`**。

同时会写入：开始菜单（「文件互传助手」+「卸载 文件互传助手」）、
桌面快捷方式（完成页勾选「创建桌面快捷方式」并点「完成」时）、
以及「设置 → 应用」里的卸载项（都在当前用户下，不需要管理员权限）。

> 聊天记录、配对关系和收到的文件属于用户数据，仍在 `%APPDATA%\ADBTypeLink`
> 与下载目录里，不随安装位置变化。

## 静默安装（可选）

```powershell
.\文件互传助手-2.2.0-安装包.exe /S                 # 默认选项安装，含桌面快捷方式
.\文件互传助手-2.2.0-安装包.exe /S /D=D:\Tools\文件互传助手   # 指定目录（/D 必须放最后，路径不要加引号）
```

## 卸载

「设置 → 应用 → 文件互传助手 → 卸载」，或开始菜单 → 文件互传助手 → 卸载。

卸载只删除程序本身（安装目录里的文件、开始菜单、桌面快捷方式和卸载注册项）；
聊天记录、配对关系和收到的文件都还在
（数据目录 `%APPDATA%\ADBTypeLink`，接收目录默认 `%USERPROFILE%\Downloads\ADBType 接收`）。
需要彻底清除时手动删除这两个目录即可。

## 系统要求

- Windows 10 1809+ / Windows 11，64 位（x64）
- 首次运行请在 Windows 防火墙里允许「专用网络」（发现用 UDP 52730，传输用随机 TCP 端口）；
  如果当前 Wi-Fi 被识别成「公用网络」，广播会被丢弃，需要改成「专用网络」

## 未签名提示

安装包和程序都没有做代码签名，首次运行时 Windows SmartScreen 可能提示
「Windows 已保护你的电脑」：点「更多信息 → 仍要运行」即可。
