## macOS 文件浏览窗口

- 「移动设备」页新增独立的文件浏览窗口，支持常用目录、路径跳转、隐藏文件、返回 / 上一级；
- 精确文件路径会进入父目录并选中文件，不会直接打开；
- 软链接目录会解析后跳转；根目录隐藏系统软链接和不可访问项；
- `/data/data` 普通 shell 读不到时，用 `pm list packages` 显示包名；debuggable 应用可通过
  `run-as` 进入查看数据，且该目录保持只读；
- 右键新建文件 / 文件夹、右键上传、右键刷新、下载到 Mac、复制路径、删除；
- 所有删除入口（右键 / ⌘⌫）都强制确认，默认按钮为「取消」。

## 多选与右键规则

- 单击单选；Shift 连选；⌘ 单击追加 / 取消多选；
- 所有选中项使用蓝色填充背景；
- 多选后单击任意一行（包括已选中的行）会清空其它选择，只保留点击项；
- 多选后右键已选中的行：保留多选，但「新建」「上传」「打开」置灰；
- 右键未选中的行：取消其它选择，只选中该行，菜单恢复正常；
- 多选下载：选择一次目标文件夹，按原文件名直接保存，目录递归下载，不重命名；
- 多选复制路径：所有路径用换行符拼接后一次复制；
- 右键文件夹「上传到此文件夹…」会传入该文件夹；右键文件 / 空白处上传到当前目录。

## 列表 / 网格视图

- 「前往」后面新增列表 / 网格切换按钮，按钮图标随状态切换；
- 网格模式下图片、GIF、视频显示缩略图，其它文件显示图标、名称和大小；
- 文件名单行、中间省略；所有卡片固定同高，文件夹也保留大小行（显示 `—`），卡片背景对齐；
- 缩略图缓存到临时目录，避免反复通过 adb 拉取；GIF 取首帧，视频用 AVFoundation 取帧。

## 安装与升级

- 下载 dmg 后双击挂载，把「文件互传助手.app」拖进「应用程序」，覆盖旧版；
- 或使用 zip 解压后运行「授权并安装.sh」；
- 升级只替换 App，不修改已有聊天记录、配对关系和接收文件；
- macOS 13+，通用二进制（Apple 芯片 / Intel），本地临时签名、未公证。
