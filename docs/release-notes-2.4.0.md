## 文件窗口搜索与类型过滤

- 路径输入框正下方新增搜索栏和「全部 / 图片 / 视频」过滤选项；
- 搜索只针对**当前目录**，支持包含匹配和字符顺序模糊匹配，不递归子目录；
- 类型过滤与搜索叠加生效：例如输入 `screen` 并选择「图片」；
- 图片过滤只显示图片文件，视频过滤只显示视频文件；「全部」显示文件夹和所有文件；
- 过滤后自动清理不可见的选中项；没有匹配时显示「没有匹配的文件」；
- macOS 使用分段按钮，Windows 使用下拉选项；列表和网格模式共用同一套过滤结果。

## ADB 文件管理：文件窗口

「移动设备」页的设备卡片新增独立的「文件」窗口，macOS 与 Windows 行为一致：

- **目录浏览**：左侧常用位置（内部存储 / 下载 / 图片 / 相机 / 临时目录 / 应用数据 / 根目录），
  路径栏支持返回、上一级和「前往」；输入精确文件路径时进入父目录并选中该文件，不直接打开；
- **列表字段**：名称、大小、修改时间、权限；文件夹优先排序；隐藏文件可切换显示；
- **根目录保护**：隐藏 `bin` / `d` / `etc` / `cache` / `init` 等系统软链和不可访问项；
  软链接先解析目标，是目录才跳转，是文件才下载；
- **搜索与过滤**：路径框下方独立一行，支持当前目录模糊搜索 + 全部 / 图片 / 视频叠加过滤；
  搜索不递归子目录，过滤后自动清理不可见选中项；
- **列表 / 网格**：网格卡片等宽等高、文件名单行中间省略；图片 / GIF / 视频异步缩略图，
  macOS 使用 ImageIO / AVFoundation，Windows 使用 Avalonia + Windows Shell 缩略图；
- **多选**：macOS `Command` + 单击切换、`Shift` 连选；Windows `Ctrl` / `Shift`；单击单选；
- **右键菜单**：新建文件 / 文件夹、上传到当前目录 / 上传到此文件夹、打开、下载、复制路径、刷新、删除；
  在已选中的行上右键保留多选，但新建 / 上传 / 打开置灰；在未选中的行上右键改为单选；
- **下载**：单个文件使用保存面板；多选或文件夹选择目标目录，按原名称保存，文件夹递归下载；
- **上传**：支持文件和整个文件夹，可上传到当前目录或右键指定文件夹；上传中显示进度；
- **新建 / 删除**：新建支持空文件和文件夹，成功后刷新并选中；删除必须确认，
  文件夹删除会连同内容删除；应用数据目录禁止新建、上传、删除；
- **复制路径**：多选时每行一个路径，用换行符拼接后一次复制；
- **/data/data**：普通 shell 无权限时用 `pm list packages` 列出包名；debuggable 应用可用
  `run-as <包名> ls -la ...` 浏览 files / shared_prefs / cache；非 debuggable 应用只显示包名；
  该区域始终只读，不需要 root。

## ADB 文件传输：快速推送到手机

移动设备页还保留轻量的「待发送列表」，用于快速推送少量文件：

- macOS 支持拖拽、文件选择、剪贴板文件 / 图片 / 文本；Windows 支持文件选择；
- 默认目标目录 `/sdcard/Download`，可修改并持久化；只接受手机路径；
- 点击「传到手机」后逐个执行 `adb push -p`，每项和整体都有百分比进度；
- 列表只接受**单个文件**，不支持文件夹；需要传目录请使用文件窗口的上传；
- 文件名保持不变，同名文件按 adb 行为覆盖，不自动重命名；
- 某个文件失败不会回滚已成功的文件，失败项保留错误信息；
- 这是电脑 → 手机单向通道；手机 → 电脑请用文件窗口下载，或电脑设备聊天的文件消息。

## ADB 截屏

- 设备卡片「截屏」执行 `adb -s <serial> exec-out screencap -p`；
  用 `exec-out` 而不是 `shell`，避免部分设备把换行转成 CRLF 损坏 PNG；
- 抓取后在独立可缩放窗口预览，可刷新、保存、选择保存目录（默认系统「下载」）；
- 保存为 `截屏-yyyyMMdd-HHmmss.png`，同一秒重名自动追加 `(2)`、`(3)`；
- macOS 支持触控板捏合缩放、双击、拖拽平移、1:1；Windows 支持滚轮缩放、拖拽、1:1；
- 保存成功显示 toast / 状态提示；Windows 可直接定位最近保存的文件夹；
- 截屏不经过云服务，不调用系统屏幕录制权限，完全由手机端 `screencap` 完成。

## macOS 其他更新

包含 2.3.0 的文件浏览、多选、右键菜单、列表/网格、缩略图和批量操作能力；
本版仅新增当前目录搜索与类型过滤，协议和聊天缓存格式不变。

## Windows 其他更新

Windows 文件管理窗口已复刻 macOS：常用目录、路径跳转、精确路径定位、隐藏文件、
列表/网格、图片/GIF/视频缩略图、Ctrl/Shift 多选、右键新建/上传/刷新/复制路径/
下载/批量删除、/data/data 包名与 run-as 浏览；本版新增当前目录搜索与类型过滤。

## 安装与升级

- macOS：下载 `文件互传助手-2.4.0.dmg`，拖进「应用程序」覆盖旧版；
- Windows：下载 `文件互传助手-2.4.0-安装包.exe`，按向导选原安装目录覆盖安装（内置 .NET 8 运行时）；
- 升级只替换 App，不修改聊天记录、配对关系和接收文件。
