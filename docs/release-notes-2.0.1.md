# 文件互传助手 2.0.1

局域网直连的电脑互传 + 手机 ADB 输入/文件传输工具。不登录、不传云、没有服务器。

## 本次更新

- macOS：红色关闭按钮改为**最小化到 Dock**，进程和后台互传继续运行；点 Dock 图标还原。
- Windows：关闭窗口收进**托盘**，后台继续收发；左键托盘图标恢复。
- macOS：文件消息对应文件不存在时显示**删除线 +「文件已不存在」**；右键菜单支持复制文字、查看文件、打开文件位置/接收目录。
- 两端均支持**已配对好友、本地别名、每设备独立会话缓存、离线保留、自动/手动重连**。
- macOS 2.0.1 / Windows 2.0.1 使用同一套局域网协议与缓存格式，可混用。
