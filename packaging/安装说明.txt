ADB 输入 · macOS 小工具（v1.2）
=====================================

不需要 Xcode，也不需要注册任何账号，双击就能用。
这一版新增：电脑之间的局域网互传（macOS ↔ Windows），像微信一样聊天收发文字和文件。


一、安装（推荐用附带的脚本，一步到位）
-------------------------------------
1. 打开 ADBType-1.2.dmg（或解压 ADBType-1.2-macOS.zip）。
2. 打开「终端」（启动台搜 Terminal），输入 bash 加一个空格，
   再把「授权并安装.sh」拖进终端窗口，回车：

       bash /Volumes/ADB 输入/授权并安装.sh

   脚本会自动：把 App 装进「应用程序」→ 解除隔离标记
   （首次打开被拦就是它造成的）→ 校验签名 → 打开 App。
   如果提示没有权限，按弹窗输入开机密码即可。

   说明：这是一个可执行的 shell 脚本，不是文档；也可以在终端里
   cd 到脚本所在目录后执行  ./授权并安装.sh

3. 不想用脚本的话，手动也可以：
   · 把「ADBType.app」拖进「应用程序」；
   · 第一次打开：右键点 App →「打开」→ 再点「打开」；
   · 若提示「已损坏」，在「终端」执行：
       xattr -dr com.apple.quarantine /Applications/ADBType.app
   · macOS 15 及以上还可以：系统设置 → 隐私与安全性 → 点「仍要打开」。

   这个 App 不会上传任何数据，只在局域网内直连另一台电脑。


二、电脑上需要有 adb（只有手机输入功能需要）
-------------------------------------
App 不自带 adb（避免和你已有的 Android 工具冲突）。
· 装了 Android Studio：adb 一般在 ~/Library/Android/sdk/platform-tools/adb，
  App 会自动找到；
· 没装：下载 https://developer.android.com/tools/releases/platform-tools
  解压到任意目录，或执行  brew install --cask android-platform-tools 。

打开 App 后，右下角会显示当前用的 adb 路径；没找到就点齿轮手动选
platform-tools 里的 adb 文件。


三、连接手机
-------------------------------------
1. 设置 → 关于手机 → 连点「版本号」7 次，开启开发者选项；
2. 开发者选项 → 打开「USB 调试」；
3. 数据线连到 Mac，手机上点「允许 USB 调试」；
4. App「移动设备」页选中设备，输入内容，按 Enter 发送。

· 纯英文 / 数字：按钮是「发送到输入框」，直接打进手机当前光标位置；
· 含中文 / emoji：按钮是「发送到设备剪贴板」，文字会写进手机剪贴板，
  你到手机上长按输入框、点「粘贴」即可（会覆盖手机剪贴板原来的内容）。


四、电脑之间互传（电脑设备页，像微信一样聊天）
-------------------------------------
1. 两台电脑连同一个 Wi-Fi / 局域网；
2. 都打开 ADBType，进入「电脑设备」页；
3. 左边「附近设备」里会出现对方，点一下选中；
4. 首次发送需要配对：左边显示本机的 6 位配对码，把它告诉对方，
   对方点「配对…」输入；输错会提示重试，输对一次以后就不用再输；
5. 下面就是聊天框：
   · 在底部输入框打字，按 Enter 或点发送按钮；
   · 点回形针或把文件拖进窗口 → 文件进入「待发送」列表 → 点「发送文件」；
   · 收到的文字/文件、发出去的内容都会留在聊天记录里，重启不丢；
   · 收到的文件保存在「接收目录」，可在左侧修改，或在「⋯」里打开；
6. Windows 电脑需要运行配套的 ADBTypeLink（用 windows/ 里的源码构建），
   界面和用法与 macOS 端一致，两端可以直接连。

· 第一次打开如果系统询问「是否允许 ADBType 查找本地网络设备」，请点允许；
  否则会搜不到对方。可在 系统设置 → 隐私与安全性 → 本地网络 里修改。
· 公司/酒店网络可能禁止设备互访，必要时换成手机热点再试。
· 传文件时两台电脑都要保持 App 打开，传完再关。


五、常见问题
-------------------------------------
· 搜不到对方：确认同一 Wi-Fi、都打开了 App、防火墙/本地网络权限已放行；
  有的路由器开了「AP 隔离」，需要关掉。
· 配对码不对：让对方看一眼他屏幕上（左侧「本机」区域）的 6 位数字。
· 聊天记录在哪：~/Library/Application Support/ADBType/chat.json；
  接收目录默认 ~/Downloads/ADBType 接收。
· 清空聊天记录不会删除已经收到的文件。


系统要求：macOS 13 及以上，Apple 芯片 / Intel 都能运行。
Windows 端：Windows 10/11，.NET 8（构建方式见 windows/README.md）。
